# 使用指南

## 1. 当前推荐路线（2026-03）

1. `lite` 场景优先使用 `react-infinite-viewer`，通过 `ViewportLite` 或 `ViewportModeHost` 接入。
2. `game/map` 场景使用 `pixi-viewport`，通过模式化入口统一管理。
3. `Viewport2D`（自研实现）当前保留为兼容层，不建议新增业务继续依赖。

## 2. 快速开始

1. 安装依赖：`pnpm install`
2. 本地开发构建：`pnpm dev`
3. 类型检查：`pnpm typecheck`

## 3. 入口选择

1. 根入口：`2d-viewport-kit`
2. 模式入口：`2d-viewport-kit/modes`
3. 轻量模式入口：`2d-viewport-kit/mode-lite`
4. 游戏模式入口：`2d-viewport-kit/mode-game`
5. 地图模式入口：`2d-viewport-kit/mode-map`
6. UI 入口：`2d-viewport-kit/ui`

## 4. 典型用法

### 4.1 轻量场景

```ts
import { ViewportLite } from '2d-viewport-kit';

<ViewportLite
  viewBox={{ x: 0, y: 0, width: 2000, height: 1200 }}
  minScale={0.25}
  maxScale={8}
/>;
```

### 4.2 按模式自动选择

```ts
import { ViewportModeHost } from '2d-viewport-kit';

<ViewportModeHost
  mode="lite"
  liteProps={{ viewBox: { x: 0, y: 0, width: 1000, height: 800 } }}
/>;
```

### 4.3 查询引擎映射

```ts
import { resolveViewportEngine } from '2d-viewport-kit';

const descriptor = resolveViewportEngine('map');
// descriptor.engine === 'pixi-viewport'
```

## 5. 本地联调（file 依赖）

1. 在消费项目 `package.json` 添加：`"2d-viewport-kit": "file:../2d-viewport-kit-react"`
2. 在工具包项目执行 `pnpm dev` 保持 `dist/` 持续更新。
3. 在消费项目执行 `pnpm install` 后启动自身开发服务器。

## 6. 常见问题

1. 找不到模块或类型：确认 `dist/` 已生成并保持更新。
2. React 重复实例：确保消费项目安装了与 peer 兼容的 `react`。
3. 使用 `ui` 入口时报依赖缺失：按需安装 Radix 相关包。
4. `game/map` 没有渲染内容：`ViewportModeHost` 需要传入 `renderPixiMode` 渲染函数。

## 7. 迁移建议

1. 新页面优先使用 `ViewportLite` 或 `ViewportModeHost`。
2. 老页面继续用 `Viewport2D` 时，建议逐页迁移，不做一次性硬切。
3. 迁移过程中保持对外控制器语义一致（`fitToCenter`、`zoomTo`、`getCamera`、`setCamera`）。
