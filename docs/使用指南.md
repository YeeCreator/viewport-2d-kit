# 本地快速调用使用指南（最简方式）

本指南给出**最简、最省事**的本地联调用法：使用本地 `file:` 依赖 + 本项目 `tsup --watch` 持续输出构建产物。适合两个项目都在本地并行快速开发的场景。

---

## 目标

- 其他本地项目可以**直接调用本工具包导出的 API**。
- 修改本工具包源码后，**无需发布**即可被其他项目感知。

---

## 一、工具包（本项目）需要的配置与操作

本项目已有满足本地调用的关键配置（无需额外改动）：

- 已提供 `exports`、`main`、`types`，指向 `dist` 产物
- 使用 `tsup` 构建并支持 `--watch`
- `react` 为 `peerDependencies`，避免多实例冲突

**本项目开发时的推荐流程：**

1. 安装依赖（仅首次）：
   - 在本项目根目录执行：`pnpm install`
2. 启动持续构建：
   - 执行：`pnpm dev`
   - 该命令会持续输出到 `dist/`，供其他项目直接读取

---

## 二、其他项目的最简引用方式（file 依赖）

> 以另一个本地项目为例（假设它与本项目同级目录）。

1. 在其他项目的 `package.json` 中添加依赖（路径按实际调整）：

   ```json
   {
     "dependencies": {
      "viewport-kit-react": "file:../viewport-kit-react"
     }
   }
   ```

2. 在其他项目中安装依赖：
   - 执行：`pnpm install`

3. 代码中直接使用：

   ```ts
  import { Viewport2D, installPreventPageZoom } from 'viewport-kit-react';
   ```

---

## 三、联调时的推荐启动顺序

1. 在工具包项目中启动：`pnpm dev`
2. 在其他项目中启动开发服务器（如 `pnpm dev` / `pnpm start`）

> 这样可以保证 `dist` 始终最新，其他项目无需重新安装依赖即可感知变更。

---

## 四、常见问题与排查

- **找不到模块或类型**：
  - 确认本项目 `dist/` 已生成（确保 `pnpm dev` 正在运行）。

- **React 重复实例问题**：
  - 确保其他项目自己安装了 `react`，并且版本与本工具包的 `peerDependencies` 兼容。

- **路径不一致**：
  - `file:` 路径需相对于**其他项目的 package.json**。

---

## 五、可选替代方案（需要更复杂配置时）

如后续需要更稳定的联调或跨多项目协作，可考虑：

- Workspace（pnpm/yarn workspaces）
- `pnpm link` / `npm link`
- `npm pack` + `.tgz` 引用
- `yalc`

如需切换方案，再新增对应指引即可。
