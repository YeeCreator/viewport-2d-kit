# 示例集成

本文提供三类典型 2D 视口场景的示例代码，帮助你在业务项目中快速落地。

## 示例列表

- 地图编辑示例：`docs/examples/map-editor-example.tsx`
- 笔记画布示例：`docs/examples/note-canvas-example.tsx`
- 绘图工具示例：`docs/examples/drawing-tool-example.tsx`

## 地图编辑示例

- 使用 `Viewport2D` 作为核心画布容器。
- 使用 `ViewportToolbar` 与 `ViewportStatus` 作为外围控制与状态展示。
- 适用于地图点位编辑、拓扑标注等场景。

## 笔记画布示例

- 使用 `Viewport2D` 承载便签卡片。
- 使用 `ViewportOverlayMenu` 承载右键快捷操作。
- 适用于知识图谱、白板笔记、需求拆解看板等场景。

## 绘图工具示例

- 使用 `Viewport2D` 承载路径与图形。
- 使用 `ViewportToolbar` 进行缩放与适配控制。
- 适用于流程草图、轻量矢量编辑等场景。

## 集成提示

- 纯核心能力请使用 `viewport-kit/core`。
- 需要 Radix 外围控件时再引入 `viewport-kit/ui`。
- `viewport-kit/ui` 依赖 `@radix-ui/react-toolbar`、`@radix-ui/react-dropdown-menu`、`@radix-ui/react-context-menu`。
