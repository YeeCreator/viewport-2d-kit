# 示例集成

## 1. 当前示例结构

1. 地图编辑示例：`docs/examples/map-editor-example.tsx`
2. 笔记画布示例：`docs/examples/note-canvas-example.tsx`
3. 绘图工具示例：`docs/examples/drawing-tool-example.tsx`

说明：现有示例主要基于 `Viewport2D` 兼容层，后续会补齐模式化示例。

## 2. 推荐新增示例（按阶段）

1. `lite-basic-example.tsx`：仅使用 `ViewportLite`。
2. `mode-host-lite-example.tsx`：通过 `ViewportModeHost` 渲染 `lite`。
3. `mode-host-game-map-example.tsx`：通过 `renderPixiMode` 注入 `game/map`。

## 3. 模式化最小示例

```tsx
import { ViewportModeHost } from '2d-viewport-kit';

export function Example() {
	return (
		<ViewportModeHost
			mode="lite"
			liteProps={{ viewBox: { x: 0, y: 0, width: 1600, height: 900 } }}
		/>
	);
}
```

## 4. game/map 注入示例

```tsx
import { ViewportModeHost } from '2d-viewport-kit';

export function PixiHostExample() {
	return (
		<ViewportModeHost
			mode="map"
			liteProps={{ viewBox: { x: 0, y: 0, width: 1, height: 1 } }}
			renderPixiMode={(mode) => <div>{mode} pixi view</div>}
		/>
	);
}
```

## 5. 集成提示

1. `2d-viewport-kit/ui` 仍为可选能力，按需引入。
2. 新业务建议优先模式化入口，旧示例可在迁移期继续运行。
3. 若要落地 `game/map`，请在业务项目安装并实现 Pixi 运行时视图。
