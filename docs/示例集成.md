# 示例集成

## 1. 当前示例结构

1. 地图编辑示例：`docs/examples/map-editor-example.tsx`
2. 笔记画布示例：`docs/examples/note-canvas-example.tsx`
3. 绘图工具示例：`docs/examples/drawing-tool-example.tsx`
4. 轻量模式示例：`docs/examples/lite-basic-example.tsx`
5. 模式宿主示例：`docs/examples/mode-host-example.tsx`
6. Vue 业务画布壳示例：`docs/examples/vue-business-canvas-shell-example.vue`

说明：前 3 个示例主要基于 `Viewport2D` 兼容层，后 2 个示例为模式化入口示例，第 6 个示例展示 Vue 宿主如何复用业务画布壳与 bridge。

## 2. 推荐新增示例（按阶段）

1. `lite-basic-example.tsx`：仅使用 `ViewportLite`。
2. `mode-host-example.tsx`：通过 `ViewportModeHost` 注入 `game/map`。
3. `vue-business-canvas-shell-example.vue`：通过 `ViewportBusinessCanvasShell` + `useViewportHostBridge` 组装业务编辑器壳。

## 3. 模式化最小示例

```tsx
import { ViewportModeHost } from 'viewport-2d-kit';

export function Example() {
	return (
		<ViewportModeHost
			mode="lite"
			liteProps={{ viewBox: { x: 0, y: 0, width: 1600, height: 900 } }}
		/>
	);
}
```

## 4. game/map 注入示例

```tsx
import { ViewportModeHost } from 'viewport-2d-kit';

export function PixiHostExample() {
	return (
		<ViewportModeHost
			mode="map"
			liteProps={{ viewBox: { x: 0, y: 0, width: 1, height: 1 } }}
			renderPixiMode={(mode) => <div>{mode} pixi view</div>}
		/>
	);
}
```

## 5. 集成提示

1. `viewport-2d-kit/ui` 仍为可选能力，按需引入。
2. 新业务建议优先模式化入口，旧示例可在迁移期继续运行。
3. 若要落地 `game/map`，请在业务项目安装并实现 Pixi 运行时视图。
4. Vue 宿主若仍要使用自定义业务 renderer，优先复用 `ViewportBusinessCanvasShell`，不要在宿主重复维护 panel/stage/toolbar 样板。
